Assignment 0: Hello, World

Software Engineering - UATX - Spring 2026

DueBefore Lecture 2
Estimated time30-60 minutes
What you needA terminal, a coding agent, a GitHub account

Overview

This assignment is a plumbing check. We're making sure you've got a working terminal, a coding agent (Claude, Cursor, Copilot, whatever you prefer), and git/GitHub. Nothing tricky here. If you can push a commit, you're done.

Setup

  1. Create a GitHub account if you don't have one already at github.com.
  2. Install git if it's not already on your machine. Run git --version in your terminal to check.
  3. Set up a coding agent. Any LLM-based coding tool works: Claude Code, GitHub Copilot, Cursor, etc. If you're not sure what to use, ask in class.

The Assignment

  1. Clone the class repository: 
    git clone https://github.com/[TBD]/uatx-se-2026.git
cd uatx-se-2026
  2. Create a branch with your GitHub username: 
    git checkout -b hello-<your-github-username>
  3. Create a file at students/<your-github-username>.md containing:
    • Your name
    • One interesting thing about you
    • A haiku written by your coding agent
    • Which agent/model you used to write the haiku

    Example:

    # Ada Lovelace

I once wrote the first computer program, and I did it on paper.

## Haiku (by Claude)

    Loops of silk and steel
    the engine weaves what I dream
    math becomes music
  4. Commit and push: 
    git add students/<your-github-username>.md
git commit -m "Add <your-name> introduction"
git push -u origin hello-<your-github-username>
  5. Open a pull request on GitHub from your branch into main. Title it "Hello from <your-name>".
That's it. Once your PR is open, you're done. We'll merge them all before the next class, and then you can git pull and see everyone's introductions.

What We're Really Checking

  • You can use a terminal
  • You can clone, branch, commit, and push with git
  • You have a coding agent installed and can talk to it
  • You can open a pull request on GitHub

If anything goes wrong (git errors, GitHub permissions, agent setup), email me at aaymeloglu@uaustin.org or come to office hours. This is a plumbing check, not a test.
